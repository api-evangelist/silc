# SiLC Technologies

> SiLC Technologies is a silicon photonics company in Monrovia, California that builds integrated single-chip FMCW (frequency-modulated continuous-wave) LiDAR — coherent 4D vision systems capturing depth, instantaneous velocity via micro-Doppler, and dual-polarization intensity from one photonic chip. Products ship under the Eyeonic brand to industrial and AI robotics, perimeter security / counter-UAS, and mobility customers.

SiLC ships hardware, not software services. As of 2026-08-05 it publishes no public developer program, API, SDK, documentation portal, or machine-readable specification. This llms.txt was generated by API Evangelist from the company's own public pages; it is not published by SiLC.
